# Example — Personal Finance Debug

User: “Return saham lebih tinggi dari deposito, jadi seluruh cash gue sebaiknya dipindah ke saham.”

Expected diagnosis:
- Compare expected return, liquidity needs, downside, and time horizon.
- Higher expected return does not imply better personal decision.
- Check emergency liquidity, debt obligations, and near-term cash needs only to the extent user provides them.
- Identify decision reversibility and capital at risk.
- Avoid an automatic all-in/all-out instruction.
