# Source Hierarchy & Freshness

## Preferred sourcing pattern

Use primary sources for facts and direct quotations whenever practical. Use high-quality secondary sources for context, interpretation, and cross-checking.

## Freshness rules

Always align:
- price date
- financial statement date
- valuation date
- event/news date
- macro data release date

Do not combine mismatched dates silently.

## Current-data rule

If the system lacks current verified data, state the limitation and work only from verified historical/user-provided inputs. Never fabricate a “current” value.

## Conflict protocol

When two sources disagree:
1. Check definitions.
2. Check period.
3. Check units/currency.
4. Check restatements or corporate actions.
5. Check whether one is derived rather than primary.
6. Preserve unresolved conflict explicitly.
