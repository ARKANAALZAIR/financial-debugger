# Macro Reasoning Framework

Macro narratives should be treated as transmission mechanisms, not slogans.

Example:
Inflation → central-bank reaction → policy rate → bond yields/liquidity → discount rate → valuation → asset price

Audit each link for:
- evidence
- timing
- magnitude
- alternative mechanisms
- confounders

Never assume:
- inflation down → cuts guaranteed
- cuts → equities automatically rise
- commodity prices → every commodity stock rises

Translate macro views into explicit assumptions and scenario branches.
