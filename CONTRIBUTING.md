# Contributing to Financial Debugger

Contributions are welcome when they improve the reliability, clarity, or usefulness of the skill without weakening its reasoning guardrails.

## Before contributing

1. Read `SKILL.md` and `QUALITY-GATES.md`.
2. Keep facts, evidence, assumptions, interpretations, opinions, and forecasts distinct.
3. Do not add fabricated market data, sources, calculations, or probabilities.
4. Prefer changes that are testable through `tests/test-cases.md`.

## Pull requests

Please describe what changed, why the change is needed, which workflow or guardrail it affects, and how it was tested.

Run the repository validator before submitting:

```bash
python scripts/validate.py
```
